# Ícone Sonora

Fonte: `sonora-icon-source.png`, criada com o gerador de imagens integrado do Codex em 2026-09-05.

Direção: waveform branco quente sobre um quadrado grafite arredondado, seguindo a identidade Quiet by default de `DESIGN.md`.

Regenerar os formatos de distribuição na raiz do projeto:

```powershell
npm run tauri icon -- src-tauri/branding/sonora-icon-source.png
```

Prompt de geração:

```text
Use case: logo-brand. Asset type: production Windows desktop app icon for Sonora, a quiet voice dictation utility. Create ONE finished square icon, 1024x1024. Design: a near-black #181816 rounded square tile with a centered warm-white #f7f7f4 abstract voice waveform made of five bold vertical pill strokes, heights short, medium, tall, medium, short. Elegant balanced spacing, strong distinctive silhouette, extremely clear at 16 and 32 pixels. Tile occupies 90 percent of image width with small even transparent outer margin; rounded corners. Flat monochrome vector-like finish, crisp geometry, restrained premium desktop utility identity. Real transparent background outside tile. No text, no letters, no orange, no gradients, no glow, no 3D, no mockup, no additional objects, no drop shadow. The app's visual identity is Quiet by default, warm white surfaces and near-black controls, with a compact black waveform bar.
```
